# Cantinho Mágico — Esculturas Artesanais em Biscuit

Landing page e portfólio interativo para ateliê de personagens e esculturas artesanais em biscuit.

## ✨ Recursos

- **Vitrine e Portfólio**: Apresentação das criações com status de vendido ("Vendido") e detalhes de cada peça.
- **Catálogo Completo**: Página dedicada com filtros por categoria, busca textual e seção de dúvidas frequentes (FAQ).
- **Sistema de Encomendas Personalizadas**: Modal interativo com formulário de personalização de cores, tamanho, personagem e detalhes.
- **Integração com WhatsApp**: Envio automatizado dos detalhes do pedido para o WhatsApp do ateliê.
- **Design Responsivo & Acessível**: Identidade visual inspirada na natureza ("Floresta Encantada"), layout mobile-first e tipografia refinada.
- **Rascunho Automático**: Salva o progresso do formulário de encomenda no `localStorage`.

## 🛠️ Tecnologias

- HTML5 Semântico
- CSS3 (Variáveis CSS, Flexbox, Grid, Animações suaves)
- JavaScript Vanilla (sem dependências externas)
- Fontes Google (Cinzel Decorative, Playfair Display, Inter)
